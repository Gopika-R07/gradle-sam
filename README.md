
# Gradle Model Questions 21–24

## Aim
To develop Java applications using Gradle, perform JUnit testing,
and package the applications as JAR files.

## Programs
1. Simple Interest
2. Average of Five Numbers
3. Vowel or Consonant
4. Area and Perimeter of Rectangle

## Requirements
- Java JDK
- Gradle
- IntelliJ IDEA

## Run the application

```bash
./gradlew run
```

## Build JAR

```bash
./gradlew jar
```

## Execute JAR

```bash
java -jar app/build/libs/app.jar
```

## Run JUnit tests

```bash
./gradlew test
```

## GitHub Pages
1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select main branch and /docs folder.
5. Click Save.

## Result
The Java applications were developed using Gradle,
tested using JUnit, and packaged into a JAR file.
